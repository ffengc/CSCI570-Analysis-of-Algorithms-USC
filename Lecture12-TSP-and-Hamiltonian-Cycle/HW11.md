## Question1

Given an undirected graph $G=(V,E)$, and positive integer $k$, the max-degree-spanning-tree (MDST) problem asks whether $G$ has a spanning tree whose degree is at most $k$. The degree of a spanning tree T is defined as the maximum number of neighbors a node has within the tree (i.e., a node may have many edges incident on it in G, but only some of them get included in T). Show that the max-degree-spanning-tree (MDST) problem a) is in NP. (4 pts) b) is NP-hard. (16 pts)

### (a) Define the Decision Version

We define the decision version of the MDST problem as follows:

> Input: An undirected graph $G=(V,E)$ and a positive integer $k$.
>
> Question: Does there exist a spanning tree $T$ of $G$ such that the maximum degree of any vertex in $T$ is at most $k$ ?

### (a) Showing the Problem is in NP

Now we need to show that the problem is in NP.

**Certificate:** A spanning tree $T$ of $G$, represented, for example, a list of its $|V|-1$ edges.

**Certifier:** Given a graph $G$ and a tree $T$, we need to check:

- there is $|V|-1$ edges in the tree $T$, because it's a spanning tree
- check that $T$ is connnected
- for each vertex $v$ in $T$, check its degree and compute $\max_{v\in V}\deg_T(v)$
- accept iff $T$ is a spanning tree and $\max_{v\in V}\deg_T(v) \le k$

all these checks and computation can be done in poly-time, therefore MDST problem is in NP.

### (b) Reduction from HC

Hamiltonian Cycle Problem:

> Input: An directed graph $G = (V, E)$
>
> Question: Does there exist a simple path that visits every vertex in $V$ exactly once?

we already known that the HC problem is NP-Complete.

Now, we need to prove that $\text{HC} \le _p \text{MDST}$.

Given an instance $G = (V, E)$ of the Hamiltonian Cycle proble, we construct instance $(G, k)$ of MDST as follows:

- Let $G = G$
- Set $k = 2$

this transformation clearly runs in poly time, since we just copy the graph and set a constant k.

### (b) Correctness of the Reduction

**First, we prove that if G has a HC, then MDST (G, 2) = YES**

Assume there is a HC with the vertices: $v_1, v_2, v_3, ..., v_n$.

Consider the edges in HC: $T = \{(v_1, v_2), (v_2, v_3), ..., (v_{n-1}, v_n)\}$

Obviously, $T$ is a spanning tree, because:

- there are $|V|-1$ edges in $T$
- it connects all the vertices

Moreover, since $T$ is from HC path, therefore, the degree of each vertices in $\{v_1, ..., v_n\}$ are at most 2. Therefore, the MDST answers YES.

**Second, we prove that if MDST (G, 2) = YES, then we have a HC**

Assume that MDST (G, 2) = YES, there is a spanning tree $T$, and the vertices in $T$ are at most 2.

- $T$ connects all the vertices in $G$
- It has exactly $|V|-1$ edges and includes all vertices

Additionally, every vertex in $T$ has degree at most 2. A connected acyclic graph where every vertex has degree $\le$ 2 must be a simple path (a tree where all internal ndoes have degree 2 and possibly two endpoints of degree 1). Therefore, $T$ is a spanning path going through every vertex exactly once - i.e., a Hamiltonian Cycle of $G$.

Hence, if MDST (G, 2), then G has a HC.

### Conclusion

Therefore, we have proved  that $\text{HC} \le _p \text{MDST}$. Therefore, MDST problem is NP, and it is NP-Hard.

## Question2

The k-cycle-decomposition problem (for any k > 1) is as follows: The input consists of a connected graph G=(V , E) and k positive integers a1, …, ak **<** |V|. The goal is to determine if there exist k disjoint cycles of sizes a1, …, ak respectively, s.t., each node in V is contained in exactly one cycle. Show that the k-cycle-decomposition problem (for any k > 1) a) is in NP. (4 pts) b) is NP-hard. (16 pts)

### (a) Showing the Problem is in NP

Certificate: explicit list of the k cycles (each given as an ordered list of vertices)

Certifier:

1. each list forms a simple cycle
2. the cycles are vertex-disjoint
3. the sizes match the required $a_1, ..., a_k$
4. the union of all cycle vertices equals $V$

all checks run in poly-time, so k-cycle-decomposition is in NP

### (b) Reduction from HC

We reduce from the Hamiltonian Cycle (HC) problem, which is NP-complete on connected graphs.

Given an HC instance G=(V,E), construct a new graph G' and parameters (k,a_1,a_2) as follows:

1. Start with all vertices and edges of G.

2. Add three new vertices $x,y,z$.

3. Add edges $(x,y),(y,z),(z,x)$, forming a triangle of size 3.

4. Pick any vertex $v_0 \in V$ and add one edge $(x,v_0)$ to keep the graph connected.

5. Set

   $k = 2,\qquad a_1 = |V|,\qquad a_2 = 3$.

Note that in the new graph $G$,

$|V|=|V|+3$, $a_1 < |V|, a_2 < |V|$

so all constraints of the problem are satisfied.

This construction clearly runs in polynomial time.

### (b) Correctness of the Reduction

**(⇒) If G has a Hamiltonian cycle, then G′ has the required 2-cycle decomposition.**

If G contains a Hamiltonian cycle C visiting all vertices of V, then in $G'$:

- Let $C_1 = C$. It is a simple cycle of size $|V| = a_1$.
- Let $C_2 = (x,y,z,x)$. This is a simple cycle of size 3 = $a_2$.

These cycles are vertex-disjoint and together cover all vertices of $V' = V \cup \{x,y,z\}$.

Thus ($G',2,|V|,3$) is a YES-instance.

**(⇐) If G′ has the required cycle decomposition, G has a Hamiltonian cycle.**

Suppose G' can be decomposed into two vertex-disjoint cycles $C_1,C_2$ with sizes

$|C_1| = |V|$ and $|C_2| = 3$.

Because y and z only connect to x and each other, any simple cycle containing y or z must be exactly the triangle $(x,y,z,x)$.

Thus $C_2$ must be this triangle.

Therefore all original vertices V must appear in $C_1$, making it a simple cycle of size $|V|$ in the original graph G.

Hence $C_1$ is a Hamiltonian cycle of G.

### Conclusion

Therefore, k-cycle-decomposition problem is NP-Hard.

## Question3

Given a graph G = (V , E) with an even number of vertices as the input, the HALF-IS problem is to decide if G has an independent set of size $|V|/2$. Prove that HALF-IS is a) is in NP. (4 pts) b) is NP-hard. (16 pts)

### (a) Showing the Problem is in NP

Certificate: A set $S \sube V$ of size $|V|/2$

Certifier:

1. we need to check $|S| = |V|/2$
2. for every pair $u, v\in S$, check $(u, v) \notin E$

These checks take poly-time (at most $(|V|/2)/2$ edge checks). Therefore, $\text{HALF-IS} \in NP$

### (b) Reduction from Independent Set (IS)

we need to prove that $\text{IS} \le _p \text{HALF-IS}$, we need to prove that: $G \text{ has an IS of size } k \;\Longleftrightarrow\; G' \text{ has an IS of size } |V'|/2$.

First, let $V_1 = V$. So these vertices behave exactly as in IS.

then, we add a second set of dummy vertices

add a new set $V_2$ with: $|V_2| = 2k-|V|$

These dummy vertices will help "balance" the size so that half of the graph equals $|V| + 2k-|V| = 2k$

Then, we add edges among new vertices:

Make $V_2$ a clique (fully connected).

This forces HALF-IS to never pick more than 1 vertex from $V_2$ -- in fact it forces that we pick zero from $V_2$.

Then, we make every vertex in $V_1$ adjacent to every vertex in $V_2$. Then no independent set may mix vertices from $V_1$ and $V_2$.

**Final graph:**

$G' = (V', E') \quad\text{where}\quad V' = V_1 \cup V_2$

$|V'| = |V| + 2k-|V| = 2k$

We set the HALF-IS target to:

$|V'|/2 = k$

But to force that the chosen half must contain *exactly k from V* and 0 from V₂, we add two dummy isolated vertices if needed (balancing trick).

### (b) Correctness of the Reduction

**(⇒) If G has an independent set of size k**

Then selecting exactly that k vertices (and no dummy vertex) forms an IS of size $|V'|/2$ in $G'$.

Because:

- All dummy vertices form a clique 
- Dummy vertices are connected to all real vertices 

**(⇐) If G' has an independent set of size |V’|/2**

Because:

- Dummy vertices form a clique
- But |V’|/2 > 1
- And must contain at least k of them

Thus original graph G has an independent set of size k.

### Conclusion

Therefore, we prove that $\text{IS} \le _p \text{HALF-IS}$, therefore HALF-IS is NP-Hard.
